## Evidence boundary

Documentation, source inspection, synthetic validation, interface smoke checks, and live behavioral tests establish different claims.

A working command does not prove approval, cancellation, isolation, recovery, or interoperability. Two products naming the same protocol do not become a demonstrated integration.

Read the [comparison methodology](/apply/comparison-methodology/) before treating any cell as a general product claim.
