## How to read the evidence

The matrix deliberately separates **what documentation says** from **what this project actually tested**.

A working command does not prove approval, cancellation, revocation, isolation, or recovery semantics. Likewise, two products mentioning the same protocol are not automatically marked compatible.

Read the [comparison methodology](/apply/comparison-methodology/) before treating any cell as a general product claim.

## External review

v0.3 does **not** claim independent community validation. No qualifying external reproduction report was received before the release candidate.

Read the [external validation status](/apply/external-validation/) or use the public review template in the specification repository to challenge the model with a real operational failure.
