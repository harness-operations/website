This is a **factual operational comparison**, not a leaderboard.

It compares scoped interfaces by architectural role and keeps finding, delivery mechanism, evidence/outcome, review date, material configuration, and limitations independently visible.

**Unknown is not unsupported. Not applicable is not a failure. A failed live test is not partial support. A shared protocol is not proof of tested interoperability.**

For definitions and correction rules, see the [comparison methodology](/apply/comparison-methodology/).

## Corrections

Every substantive cell links to its evidence. If a product changed or a finding is wrong, open an issue or pull request against the canonical comparison data with the exact interface/version/configuration, disputed capability, and primary-source or reproducible evidence.

The comparison does not imply affiliation, endorsement, certification, universal security, or overall product quality.
