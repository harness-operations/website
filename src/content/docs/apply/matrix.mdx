This matrix is a **factual operational comparison**, not a leaderboard.

It compares scoped interfaces by architectural role and preserves five separate facts for every capability: the finding, delivery mechanism, evidence, review date, and limitations.

**Unknown is not unsupported. Not applicable is not a failure. A shared protocol is not proof of tested interoperability.**

For definitions and correction rules, see the [comparison methodology](/apply/comparison-methodology/).

## Corrections

Every substantive cell links to its evidence. If a product changed or a finding is wrong, open an issue or pull request against the canonical comparison data in the specification repository with the exact interface/version, disputed capability, and primary-source or reproducible evidence.

The matrix does not imply affiliation, endorsement, certification, or a general security guarantee.
